# Srinivas Chundi — Software & AI Engineer Portfolio

A modern, responsive personal portfolio built with React, TypeScript, Tailwind CSS, Framer Motion, and Material Design 3 principles.

## 🚀 Key Features

- **Material 3 Expressive Design**: Clean steel blue `#93ccff` palette, scalloped Material 3 Cookie shapes, and subtle glassmorphism.
- **Interactive Sandbox & Terminal**: Full developer console supporting live commands (`help`, `bio`, `skills`, `projects`, `sudo hire`).
- **PDF Resume Digital Preview**: One-click dynamic PDF generation and preview modal.
- **Responsive Layout**: Designed for mobile, tablet, and desktop screens with custom liquid motion physics.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS v4, Framer Motion, Lucide Icons
- **Backend & AI Integrations**: Java, Spring Boot, Python, FastAPI, LangChain, FAISS, Groq API
- **Build Tool**: Vite

## 💻 Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```
